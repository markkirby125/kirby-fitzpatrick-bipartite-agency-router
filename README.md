## Core Patterns

- **Bipartite Agency Router**: Bipartite Agency Protocol: use 'I/we' in PR proposals to claim personal responsibility; use agentless passive in runbooks/post-mortems.
- **Practical Application**: Writing professional runbooks, post-mortems, and release notes.
- **Verification Gate**: Enforces clean syntax, zero filler, and deterministic causality.
